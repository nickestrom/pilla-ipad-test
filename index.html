Speed test: which drawing method is fastest

Eight ways to draw the same two moving scenes. Open each, do what it says, and write down the frame rate shown in the bottom right corner (the lowest and highest number you see while it moves). Then go back and open the next one. The pictures should look the same in all of them; note it if one looks wrong.
