Speed test: which drawing method is fastest

The figures now draw with split layers and blur-free glows by default. Each scene comes in two versions: the new default and the old method. Open each, do what it says, and write down the frame rate shown in the bottom right corner (the lowest and highest number you see while it moves). Then go back and open the next one. The two versions of a scene should look the same; note it if one looks wrong.

Kettle diagnosis: what makes it slow

Each link opens the kettle see-through and keeps it boiling (it never switches itself off). Do nothing: wait 3 seconds, then note the lowest and highest frame rate over the next 5 seconds. Each one leaves out one thing, so the difference shows what costs the most.

A. Kettle boiling, everything onThe full picture: water moving, bubbles, steam. B. Kettle, frozen pictureSame, but nothing moves on screen. It still does all the drawing work in code each frame, so this shows the cost of the code alone. C. Kettle, no steamLike A without the steam wisps. D. Kettle, no bubblesLike A without the bubbles. E. Kettle, no steam, no bubblesLike A with only the water surface moving. F. Kettle boiling, closedNot see-through: the closed kettle with steam from the spout.
